# PICRUSt2 full output

This directory is intentionally kept out of Git for large compressed PICRUSt2 result files.

Expected large outputs include:

- `KO_metagenome_out/pred_metagenome_contrib.tsv.gz`
- `EC_metagenome_out/pred_metagenome_contrib.tsv.gz`
- `pathways_out/path_abun_contrib.tsv.gz`
- Predicted KO and EC tables such as `combined_KO_predicted.tsv.gz` and `combined_EC_predicted.tsv.gz`

The current local `picrust2_output` directory is about 2.5 GB. Keep these files locally or in external storage, and regenerate derived lightweight summaries under `data/picrust2-result/derived/` when needed.
